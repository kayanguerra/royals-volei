# Resumo do projeto
O Royals Volley é um site institucional desenvolvido para apresentar a identidade, elenco e informações principais do time de vôlei Royals. O projeto utiliza uma identidade visual esportiva e imponente, com elementos como águia, coroa e cores marcantes, reforçando a presença e personalidade da equipe.

O site conta com seções para apresentação do time, elenco por posições, destaque de MVP, galeria e contato, com foco em organização, responsividade e divulgação da marca Royals.


## ✔️ Técnicas e tecnologias utilizadas

- ``JavaScript``
- ``particles.js``

## 📝 Como atualizar fotos e conteúdo

Elenco, MVPs, jogos e galeria ficam em `content/misto.json` (time misto, tema roxo) e `content/masculino.json` (masculino, tema vermelho). O `assets/js/main.js` só lê esses arquivos.

**Pelo painel (recomendado):** entre em https://app.pagescms.org com a conta do GitHub, abra o repositório e edite. Ao salvar, o painel faz o commit e a Vercel publica sozinha.

**Fotos:** vão para `assets/gallery/`. Uma GitHub Action (`.github/workflows/otimizar-imagens.yml`) reduz automaticamente fotos acima de 400 KB ou 1600 px.

**Teste local:** o site carrega os JSON via `fetch`, então abrir o `index.html` com duplo clique não funciona. Use o Live Server do VS Code ou `python -m http.server`.
